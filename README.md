# 💼 Portafolio de Proyectos de Análisis de Datos | Jonathan García

Bienvenido a mi portafolio de proyectos de análisis de datos.

Soy analista de datos junior con experiencia en operaciones industriales y mejora continua. Me enfoco en la limpieza, transformación, análisis e interpretación de datos para convertir información en hallazgos útiles para la toma de decisiones.

Actualmente aplico y continúo fortaleciendo habilidades en análisis de datos, machine learning y visualización con herramientas como **Python, pandas, scikit-learn, SQL, Excel y Git/GitHub**.

## Perfil

Mi experiencia en entornos productivos me ha permitido desarrollar criterio para interpretar indicadores, detectar desviaciones operativas y relacionar los datos con problemas reales de proceso.

En este portafolio presento proyectos seleccionados donde aplico:

- limpieza y preparación de datos
